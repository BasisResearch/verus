Lane 2: fixed-width bit operations and partial Init

Scope: source/vir/src/tla.rs and source/rust_verify_test/tests/tla_export.rs.
Base branch: kg/export-traits. The base was 9abf2c0e during implementation.

Design
------
The basis-11305b4a05 jar contains no Bitwise module. Unsigned bit operations
are local recursive LET operators over Int, with hygienically allocated names.
They work in ordinary model operators and separately exported candidates.

For nonnegative x,y and an unsigned width w:
  x & y, x | y, x ^ y: combine the low bits and recursively combine x div 2
  and y div 2, doubling the result. Stop when both operands are zero.
  !x: 2^w - 1 - x.
  x >> n: recursively divide by two, stopping at n=0 or x=0.
  x << n: retain the low w-n bits recursively, then double n times.
  Spec shifts at/above w yield zero; executable shifts retain a source-located
  Assert for out-of-range amounts. Negative shifts also stop at an Assert.
  Signed operations and an unspecified pointer width remain located refusals.
  usize uses the crate's global size_of declaration; never assume the host width.

Recursion avoids constructing a huge power of two just to shift a small u64.
The jar still cannot represent results outside signed 32-bit integers: those
stop with TLC arithmetic overflow, never wrapping or silently weakening the
model. In particular, the actual 1 << 52 address maximum cannot execute in
this jar if the preceding opaque-constant blocker is resolved.

Partial Init enumerates every incomplete top-level value, then evaluates the
original Init predicate and TypeOK. Small finite scalar/enum/record domains
are exact; finite record products are no longer silently abandoned at the
old combination cap. Unbounded collections and scalars get Dom_<Type> holes.
The cfg must supply their finite carriers. ASSUME clauses check finiteness
and recursively constrain their element types. Both the TLA header and JSON
report explicitly warn that only values in those carriers are explored.

For example, a record {fixed: bool, free: bool} constrained only by fixed
gets its four-value record domain; Init filters to the two allowed records.
For nrkernel/os_ext, diagnostics identify shootdown_vec.vaddr and allocated
as unassigned, rather than claiming its assigned open_requests is free.
The init_enumerated entries describe the domain of each drawn whole variable.
Leaf reporting is conservative through calls passing subrecords rather than
whole states; no predicate is removed or replaced by the report.

Validation and campaign
-----------------------
Run from the worktree; before Verus/vargo commands:
  export PATH=$HOME/.cargo/bin:$PATH; export TMPDIR=$HOME/tmp
  export VERUS_MCP_ENABLED=1
  export TLA2TOOLS_JAR=$HOME/.verus-tools-mcp/tlc/basis-11305b4a05/tla2tools.jar
Then from source, use the available vargo:
  timeout 1200 ../../base/verus/tools/vargo/target/release/vargo test --release \
    -p rust_verify_test --test tla_export
Each SANY/TLC test process additionally has a 60-second timeout.

reexport.py reuses the campaign's command.json inputs without editing those
sources, redirects all output into this worktree, and applies its 90-second
export timeout. check_campaign.py runs SANY for all six exports and a separate
30-second, one-worker, 1-GiB OS-external probe. That probe is supplementary:
the original campaign stopped these six machines at export/SANY, and saved no
nrkernel MC configuration or exploration bounds. No invented bounds are
presented as a completed campaign run. The other five remain blocked by
reported refusals and are not counted as explored.

Compatibility exception (acceptance requirement not met)
--------------------------------------------------------
All six examples/tla source fixtures must compare byte-identically, including
the .tla, .cfg, trace module and JSON report. The comparison script records
that check.

The requested base/toydb working checkout is now main and has no safety.rs.
The exact source from origin/yl/raft-safety-refine at
c23eebe8c678bda4693748f8a5cbe05ddba2b2ff was extracted read-only into this
worktree and exported with the twelve invariants used by its export.sh.
Its old export reports hosts as unassigned: Init constrains the sequence's
length and every element through a forall, instead of assigning it whole.
The general partial-Init rule necessarily adds Dom_Seq_MHost and an Init
enumeration there. Therefore Toydb's module/cfg/report change (its trace
module is unchanged). Existing Toydb harnesses must supply the new carrier.
No project-name special case or out-of-lane sequence-builder rewrite was
added just to conceal this incompatibility. Keep this PR draft until the
compatibility requirement is reconciled with the general Init behavior.

Remaining blockers, ranked by number of affected machines
---------------------------------------------------------
1. Opaque MAX_PHYADDR_WIDTH: all six. Rendering the previously refused shift
   visits its operand for the first time and exposes this external_body
   constant; do not replace it with the source implementation's literal 52.
   Opaque arbitrary() also occurs in five layers. These belong to the
   traits/opaque lane below this PR.
2. ISet::finite: four machines (hlspec, mmu_rl2, mmu_rl3, os), eleven refusal
   sites. Infinite collection semantics belong to the partial-operations lane.
3. choose: hlspec and os, two sites; left to the partial-operations lane.
4. Integer-type bound: os, six sites; remains an explicit refusal.

Source locations and complete remaining refusal lists are in campaign.json.
The new features remove all 420 bit-operation refusal sites; six newly
reachable opaque-constant sites explain why total refusals fall by 414.
Every layer's previously unassigned Init variables now has an explicit domain.
This is exporter progress, not a successful verification of nrkernel.
