Design and TLA+ constructs
-------------------------
1. Generic calls whose bodies depend on dispatch or opaque functions are
   specialized by full VIR type arguments. Substitution visits parameters,
   return types, expression types and nested call type arguments. Concrete
   associated types are normalized through matching impls. The impl matcher
   compares all trait arguments, supports generic receiver patterns, and
   only selects a unique match. Existing resolved/default-method paths
   remain supported. Type-independent polymorphic helpers keep their
   original names and output. The two concrete Dispatch implementations
   in the regression test yield distinct operators, one toggling and one
   preserving the state.

2. A bodyless spec function becomes a mathematical function constant:
     CONSTANT Table_f
     f(a, b) == Table_f[<<a,b>>]
     ASSUME Table_f \in [{<<a,b>> : a \in A, b \in B} -> R]
   Nullary functions use the singleton key domain {<<>>}. All pre/post
   operator variants share the same table. Full state arguments become
   records, rather than being lost when the wrapper drops state parameters.
   The cfg gives the entire signature and CONSTANT Table_f <- SupplyFiniteTable.
   It never supplies a guessed truth value or an empty default carrier.

3. A table hole has kind=uninterpreted_function, its signature, source
   location and a warning explaining the finite interpretation. The TLA+
   header also warns. Existing hole JSON retains its previous shape.
   Dom_<T> carriers have ASSUME constraints, including integer membership
   and bounds, nested collection/record/tuple types, and explicit finite
   carriers for unresolved associated sorts. Subcarriers of the same
   abstract sort are constrained to its shared carrier. Unsupported
   higher-order or recursive carrier encodings remain refusals.

4. Expressible VIR requires/ensures constrain the table as:
     ASSUME \A a \in A : Requires(a) => Ensures(a, Table_f[<<a>>])
   Both regular and inherited ensures are retained during specialization.
   Contracts follow operator definitions but precede the module terminator.
   Current source spec functions cannot declare ensures; their requires
   field represents recommends and must not restrict a total spec function
   by itself. A direct VIR-renderer test uses TLC to accept a satisfying
   interpretation and reject an inconsistent one, including nullary
   contracts and the no-ensures case.
